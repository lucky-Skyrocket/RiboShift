# RiboShift Licensing Notice

This release package contains normalized benchmark artifacts, split assignments, generated matched-decoy candidate pools, metadata summaries, schemas, and supporting code notes prepared for the RiboShift benchmark release.

## Licensing structure

- The newly released benchmark artifacts, split files, generated matched-decoy files, metadata manifests, schemas, summaries, and benchmark-specific documentation are released under the Creative Commons Attribution 4.0 International license (CC BY 4.0).
- Upstream source datasets and database records remain governed by their original licenses, access terms, and attribution requirements.
- Provenance records are retained in the release so that downstream users can inspect the upstream source mapping and respect source-specific constraints.

## Release note

The archived public release should cite the CC BY 4.0 license for newly created RiboShift benchmark artifacts and link the stable archival record for citation and reuse. The CC BY 4.0 license does not relicense upstream source datasets or database records.
